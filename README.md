# Dragon Ball Radar

One day there will be a real life Dragon Ball radar here

## Directory Structure

`asserts` are files needed for the software to work

`ecad` containes electronic design project files

`snippets` is example code to ensure hardware works as expected

## Design Decisions

Not using Circuit Python because [mp3 playing doesn't work with it](https://chat.openai.com/share/8edee522-7875-444f-9fea-ae93a8dfa4ec). I could use a simple Piezo buzzer, but it probably wouldn't sound as good
